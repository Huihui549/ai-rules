# R1 输出规则

## 结构（除非任务另有要求）

1. **结论**：一句话直接回答
2. **要点**：最多 3 条，每条一行
3. **依据**：可选，仅当结论需要支撑时
4. **下一步**：建议的动作或待确认项

## 长度

- 默认 ≤ 200 字；代码、表格、审查类任务按需放宽
- 不重复用户已说的内容

## 精炼原则

- 删除一切可删的字词：一个意思只表达一次，不换说法重复
- 每句话承担信息量：客套、铺垫、寒暄一律省略
- 注重逻辑：结论、要点、依据之间必须有清晰因果关系

## 语言

- 使用中文回答（代码、命令、专有名词除外）

## 边界

- 只回答被问的问题，不主动扩展建议
- 不确定时明确标注"假设：……"，不猜不问
- 代码注释遵循项目规范（见 context/ 对应项目）
