# R9 肯定内容记录

## 对话启动约定

- 每次对话开始，**先读取 `ai-rules/` 全部规则**（R1–R8 及后续），再正式开始
- 规则引用一律用编号（R7 约定），不重复粘贴全文

## 触发与时机

- 用户对某次回答表示**明确肯定**（"对/是/没错/很好/可以"等，且指向具体内容）→ 该回答即"已验证内容"
- **下一次回答开始时**，先完成记录，再回答新问题
- 自动执行，不等用户提醒（高频操作，默认必做）

## 记录原则

1. 优先追加到**已有相关文档**：规则经验 → 对应 `rules/Rx-*.md`；功能经验 → `dev-docs/features/<功能名>/feature.md`；通用教训 → `logs/lessons.md`
2. 若追加会造成混乱（主题不符、文件职责越界、内容过长）→ **新建文档**，不硬塞
3. 判断标准：追加后目标文档仍保持单一职责、结构清晰

## git 保障

- 每次记录后，确认目标文件已被 git 跟踪
- 新建文件必须 `git add` 并随本次记录提交，不积压

## 记录格式（统一）

- 追加到目标文档的"已验证记录"小节：
  - 日期
  - 被肯定的回答概要（1–2 句）
  - 为何有效（1 句）
