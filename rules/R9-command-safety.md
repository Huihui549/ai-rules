# R9 敏感命令审批

> 涉及以下操作的命令，必须在说明功能、后果后请示用户，获批准方可执行；未获批不得执行。

| 命令 | 风险 |
|------|------|
| `rm` / `rmdir` | 删除文件/目录，不可逆 |
| `chmod` / `chown` | 修改权限/属主，可能致系统不可用 |
| `mv`（跨文件系统/覆盖） | 移动/重命名可能覆盖已有数据 |
| `dd` / `mkfs` / `fdisk` | 磁盘写入操作 |
| `kill` / `pkill` / `killall` | 终止进程 |
| `shutdown` / `reboot` | 系统启停 |
| `iptables` / `ufw` 规则修改 | 可能阻断网络 |
| `dpkg --purge` / `apt purge` | 可能误删系统包 |

## 请示格式

说明「命令功能 → 预期结果 → 失败后果 → 是否允许执行？」

## 与 R4 的关系

- R4 管 git 仓库内操作：AI **不执行任何 git 写操作**（只读检查按 R4 白名单），交由用户掌控；本规则管系统级命令，需前置确认
- 代码/文档修改本身按 R3 意图边界执行，不受本规则限制
