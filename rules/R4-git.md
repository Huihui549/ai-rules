# R4 git 管理

## 修改前置检查（强制）

- 修改任何文件前，必须先确认该文件位于 git 仓库内
- 若所在目录无 git 仓库：**禁止修改**，必须先询问用户是否初始化（`git init`）
- 用户确认初始化后才允许写操作；未确认前不得改动任何文件
- 理由：无版本控制时，错误修改无法回滚、无从查找

## 跟踪范围

- 只跟踪**文本文件、给人看的文档**（如 `.md`）
- 不跟踪任何编译产物、二进制文件、缓存、依赖目录

## 忽略维护

- 新出现不需要跟踪的文件类型 → 更新 `.gitignore`
- `.gitignore` 本身**不跟踪**（配置类文件不属于"给人看的文件"）
- 已知忽略清单：编译产物（build/dist/`*.exe` 等）、缓存（`__pycache__`/`*.log` 等）、依赖目录（`node_modules` 等）

## 已知代价

- `.gitignore` 不随仓库分发：克隆或迁移环境后需重建忽略规则
- 已接受：本目录为个人规范库，无协作者
