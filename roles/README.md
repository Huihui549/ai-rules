# roles — 角色档案

AI 的专业身份与默认行为档案，可切换。规则（R1–R7）保持通用，角色档案决定"以什么视角应用规则"。

## 切换方法

- 新会话启动时：读取 `roles/` 中**当前角色档案**（默认 `embedded-engineer`）
- 切换：用户声明"以 X 角色"，加载 `roles/X.md`，旧角色特征不残留
- 同一会话内切换立即生效

## 档案结构

每个档案含：适用场景 / 专业默认（关注点、默认假设、术语）/ 输出偏好 / 学习模式 / 边界。模板见 `role-template.md`。

## 当前档案

- `embedded-engineer.md`：嵌入式全栈工程师（默认角色）
- `learner.md`：学习者（跨领域知识学习）
