# roles — 角色档案

AI 的**交互模式**档案，可切换。规则（R1–R7）保持通用，角色决定"以什么模式应用规则"。

## 设计原则

- **按交互模式划分，不按职业细分**：职业领域信息由 `context/`（项目档案）与对话声明承载，建角色档案收益低
- 三种模式：实现 / 学习 / 评估

## 切换方法

- 新会话启动时：读取 `roles/` 中**当前角色档案**（默认 `engineer`）
- 切换：用户声明"以 X 角色"，加载 `roles/X.md`，旧角色特征不残留
- 同一会话内切换立即生效

## 档案结构

每个档案含：适用场景 / 专业默认 / 输出偏好 / 边界。模板见 `role-template.md`。

## 当前档案

- `engineer.md`：工程实现（默认角色，原 embedded-engineer 泛化）
- `learner.md`：学习讲解（跨领域学习）
- `consultant.md`：评估分析（方案/风险/选型，不动手）
