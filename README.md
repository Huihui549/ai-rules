# ai-rules — AI 协作规范库

约束 AI 输出与协作行为的规则库：让 AI 一次给出可用结果（结论、最优解、问题上报），不浪费用户的阅读成本与决策成本。

## 目录结构

| 路径 | 用途 |
|---|---|
| `README.md` | 索引 + 使用流程 + 命名约定 |
| `rules/` | 规则 R1–R11，**一条规则一个文件**，主题单一 |
| `roles/` | 角色档案（engineer / learner / consultant / friend），按交互模式自动切换 |
| `templates/` | 复制即用的模板：对话开场规则段、任务提示 |
| `context/` | 项目上下文模板，**每个项目一份** |
| `logs/` | 教训沉淀：记录 AI 不符合预期的行为 |

## 使用流程

1. **每次对话**：把 `templates/dialogue-opening.md` 的规则段粘贴到对话开头（零成本，立即生效）。
2. **发现新问题**：记入 `logs/lessons.md`；同类问题出现 2 次 → 按 R7 提炼为正式规则。
3. **稳定通用**：打包为 `SKILL.md` 跨项目复用（需要时再建 `skills/`）。

## 命名与格式约定

- 文件名 `kebab-case`；**字母数字简称必须作为文件名前缀**（如 `R1-output.md`），见 R7
- 规则文件**必须**带 frontmatter：`name` / `description` / `scope` / `priority`
- 规则编号 R1、R2……用于 logs 与对话引用
- **单一事实源（SSOT）**：每条规则全文只写在其归属文件，其他文件只引用编号、不重述细则（R7）

## 与工具生态对接

- **AGENTS.md / CLAUDE.md**：合并 `rules/` + `roles/` 生成后放项目根目录，支持自动加载的工具每次自动读取，省去手动粘贴
- **Skill**：稳定规则打包为 `SKILL.md` 指令包，跨项目复用

## 与项目文档的边界

- ai-rules 只放**绝对通用**的规则与模板，不含具体项目内容，也不含项目文档位置；项目专属流程/标准文档由用户提供路径，AI 按需读取（R6 目录边界、R5 渐进式披露）
